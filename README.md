# robber-game
Clobberゲームのインパーシャル版．

## 基本操作
### 最初のウィンドウ
- ↑/↓: 盤面の高さを変更
- ←/→: 盤面の幅を変更
- Enter: ゲーム開始

### ゲーム中
- クリック: 石を選択
  - 隣り合った石であれば移動可能
- R: 最初のウィンドウに移動

## ルール
- 石の色はすべて黒駒
- 隣り合った石に選択した石をまるごと乗せる
  - 高い石に対して低い石は乗せられない
- 石を乗せることができなくなったら最後に石を置いたプレイヤーが勝ち
