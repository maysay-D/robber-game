# robber-game
Clobberゲームのインパーシャル版．

## 基本操作
### 最初のウィンドウ
- ~~↑/↓: 盤面の高さを変更~~
- ~~←/→: 盤面の幅を変更~~
  - 盤面のサイズは一旦固定
- Enter: ゲーム開始
- H: ホストとしてゲームを開始
- J: ホスト側のゲームに参加
- A: エージェントと対戦（要Python実行）
  - エージェントのプログラムを動作させたい場合は``uv run python``を実行

### ゲーム中
- クリック: 石を選択
  - 隣り合った石であれば移動可能
- R: 最初のウィンドウに移動

## ルール
- 石の色はすべて黒駒
- 隣り合った石に選択した石をまるごと乗せる
  - 高い石に対して低い石は乗せられない
- 石を乗せることができなくなったら最後に石を置いたプレイヤーが勝ち
