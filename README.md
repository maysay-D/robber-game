# robber-game

Bevy最新版で実装した、Clobberのインパーシャル亜種です。

## ルール（この実装）

- 石はすべて同色（インパーシャル）
- 隣接マス（上下左右）にある石の上へ移動できる
- 移動元の石を1つ減らし、移動先の石を1つ増やす（取った石を積み上げる）
- 手番プレイヤーが合法手を持たなくなったら負け

## 操作

- タイトル画面
  - `↑` / `↓` または `+` / `-`: 盤面サイズ変更
  - `Enter` / `Space`: ゲーム開始
- ゲーム画面
  - マウス左クリック: 石を選択して移動
  - `R` / `Esc`: タイトルへ戻る

ウィンドウタイトルと背景色で、先手/後手の手番をハイライト表示します。
